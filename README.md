# mc_8_knobs

This project is based on the Raspberry Pi Pico and uses the TinyUSB library for the USB layer.

The eight rotary encoders transmit MIDI CC messages 7–14, and the eight buttons transmit MIDI note numbers 120–127 (C9–G9, using the convention where MIDI note 60 = C4).

For development, I use CLion as the IDE and a J-Link debugger.
